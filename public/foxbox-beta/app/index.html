WHAT THE APP ADDS

  • RUMBLEYour phone really buzzes when you BONK, get hit or swing.
  • MOTIONTilt and swing games just work. No motion prompt.
  • AWAKEThe screen stays on for the whole game.
  • FULL SCREENNo browser bars. It turns sideways when the game does.

INSTALL IN 3 STEPS

  1. 1

    Allow installs from Chrome

    Open the download (if Chrome asks, tap Download anyway). If Android says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.

  2. 2

    Install

    Tap Install. If Play Protect asks about the app, let it scan, then install.

  3. 3

    Open

    Tap Open. FoxBox Controller starts on the join screen.

Then: TV codes open the app

The first time, the app asks: tap Set up, then Add link, and turn on khabefox.com. Now scanning the TV's QR code with your camera opens FoxBox Controller.

Missed it? Settings → Apps → FoxBox Controller → Open by default
